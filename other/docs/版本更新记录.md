# Biomni Agent 应用文档版本更新记录

## v1.1 - 2025-01-18

### 移除功能

#### 1. 移除用户注册功能
- ❌ 移除用户自助注册接口
- ❌ 移除邮箱/手机验证码功能
- ✅ 改为管理员统一创建用户账号
- ✅ 简化用户管理流程

#### 2. 移除 API Key 功能
- ❌ 移除 `user_api_keys` 数据表
- ❌ 移除 API Key 管理接口
- ❌ 移除程序化访问功能
- ✅ 专注于 Web 界面访问
- ✅ 简化系统架构

#### 3. 移除对话分享功能
- ❌ 移除 `conversation_shares` 数据表
- ❌ 移除对话分享接口
- ✅ 简化对话管理

#### 4. 简化 Know-How 文档管理
- ❌ 移除 `knowhow_categories` 独立分类表
- ❌ 移除 `knowhow_tags` 独立标签表
- ❌ 移除 `knowhow_document_tags` 关联表
- ❌ 移除 `user_knowhow_favorites` 收藏表
- ✅ 分类和标签直接存储在文档表中（字符串字段）
- ✅ 简化数据库结构

#### 5. 移除系统监控模块
- ❌ 移除 `system_monitor_records` 表
- ❌ 移除 `application_monitor_records` 表
- ❌ 移除 `alert_configs` 表
- ❌ 移除 `alert_records` 表
- ❌ 移除所有监控相关接口
- ✅ 暂不实现监控功能，专注核心业务
- ✅ 后续可通过 Prometheus + Grafana 等外部工具实现

#### 6. 移除系统通知功能
- ❌ 移除 `system_notifications` 表
- ✅ 配额信息在个人中心实时查看
- ✅ 系统公告在登录页或首页显示
- ✅ 任务完成通过 WebSocket 实时推送
- ✅ 操作成功通过 Toast 提示

### 新增功能

#### 1. 系统初始化机制
- ✅ 应用首次启动自动初始化
- ✅ 自动创建默认管理员账号（用户名: admin）
- ✅ 随机生成 16 位强密码
- ✅ 初始密码输出到控制台日志
- ✅ 防止重复初始化

#### 2. 强制修改密码
- ✅ 首次登录强制修改密码
- ✅ 在 `admins` 表添加 `force_password_change` 字段
- ✅ 修改密码前只能访问修改密码和登出接口
- ✅ 提升账号安全性

### 数据库变更

#### 新增字段
```sql
-- admins 表
ALTER TABLE admins ADD COLUMN force_password_change TINYINT NOT NULL DEFAULT 0 COMMENT '强制修改密码: 0-否, 1-是';
```

#### 删除表
```sql
-- 移除 API Key 表
DROP TABLE IF EXISTS user_api_keys;

-- 移除对话分享表
DROP TABLE IF EXISTS conversation_shares;

-- 移除 Know-How 分类和标签相关表
DROP TABLE IF EXISTS knowhow_document_tags;
DROP TABLE IF EXISTS knowhow_tags;
DROP TABLE IF EXISTS knowhow_categories;
DROP TABLE IF EXISTS user_knowhow_favorites;

-- 移除系统监控相关表
DROP TABLE IF EXISTS alert_records;
DROP TABLE IF EXISTS alert_configs;
DROP TABLE IF EXISTS application_monitor_records;
DROP TABLE IF EXISTS system_monitor_records;

-- 移除系统通知表
DROP TABLE IF EXISTS system_notifications;
```

#### 修改表
```sql
-- knowhow_documents 表添加分类和标签字段
ALTER TABLE knowhow_documents 
ADD COLUMN category VARCHAR(100) DEFAULT NULL COMMENT '分类',
ADD COLUMN tags VARCHAR(500) DEFAULT NULL COMMENT '标签(逗号分隔)',
DROP FOREIGN KEY fk_documents_categories,
DROP COLUMN category_id;
```

#### 配置变更
```sql
-- 移除注册开关配置
-- 旧配置: {"enable_registration": true, "max_concurrent_tasks": 100}
-- 新配置: {"max_concurrent_tasks": 100, "session_timeout": 30}
```

### API 接口变更

#### 移除接口
- `POST /api/client/auth/register` - 用户注册
- `POST /api/client/auth/send-code` - 发送验证码
- `POST /api/client/auth/verify-code` - 验证验证码
- `GET /api/client/user/api-keys` - API Key 列表
- `POST /api/client/user/api-keys` - 创建 API Key
- `DELETE /api/client/user/api-keys/{id}` - 删除 API Key
- `POST /api/client/conversations/{id}/share` - 生成分享链接
- `GET /api/admin/knowhow/categories` - 文档分类列表
- `POST /api/admin/knowhow/categories` - 创建分类
- `GET /api/admin/knowhow/tags` - 文档标签列表
- `POST /api/client/knowhow/{id}/favorite` - 收藏文档
- `DELETE /api/client/knowhow/{id}/favorite` - 取消收藏
- `GET /api/client/knowhow/favorites` - 我的收藏
- `GET /api/admin/monitor/system` - 系统状态
- `GET /api/admin/monitor/history` - 历史监控数据
- `GET /api/admin/monitor/services` - 服务状态
- `GET /api/admin/monitor/performance` - 性能指标
- `GET /api/admin/monitor/errors` - 错误日志
- `GET /api/admin/monitor/alerts` - 告警配置
- `PUT /api/admin/monitor/alerts/{id}` - 更新告警配置

#### 新增接口
- `POST /api/admin/auth/change-password` - 强制修改密码

#### 修改接口
- `POST /api/admin/auth/login` - 响应中添加 `forcePasswordChange` 字段
- `POST /api/admin/users` - 响应中添加 `initialPassword` 字段

### 破坏性变更

⚠️ **注意**: 以下变更可能影响现有系统

1. **API Key 功能完全移除**
   - 如果有用户正在使用 API Key，需要通知他们改用 Web 界面
   - 现有的 API Key 将失效

2. **用户注册功能移除**
   - 用户无法自助注册
   - 需要管理员手动创建账号

3. **首次登录强制修改密码**
   - 所有新创建的管理员首次登录需要修改密码
   - 可能影响自动化脚本
