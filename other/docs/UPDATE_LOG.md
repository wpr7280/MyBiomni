# 更新日志

## 2025-01-20 - 功能完善

### ✅ 新增功能

#### 1. 附件上传
- 📎 Ant Design X Sender 组件自带文件上传功能
- 📁 点击输入框左侧的附件图标即可上传
- 🖼️ 支持多种文件格式

#### 2. 示例研究问题
- 📝 在输入框上方显示示例问题
- 🎯 点击即可快速发送
- 💡 包含 7 个生物医学领域的示例
- 🔄 发送消息后自动隐藏

**示例问题列表**：
1. 蛋白质表达分析
2. CRISPR 克隆指导
3. 遗传病因分析
4. 药物相似性分析
5. CRISPR 筛选设计
6. 遗传机制研究
7. 药物重定位

#### 3. 导出和下载
- 📥 Export & Download 按钮
- 📄 支持多种格式：
  - Markdown
  - PDF
  - JSON
- ⏸️ Stop 按钮（停止执行）

#### 4. 配额显示
- 📊 底部显示配额信息
- 🔢 每周请求次数：45/50
- 📅 Token 有效期：2025-06-02
- 🎨 使用 Tag 组件展示

#### 5. 个人中心页面
- 👤 用户信息卡片
  - 头像
  - 用户名
  - 邮箱
  - 角色
  - 用户 ID
- ✏️ 修改用户名和邮箱
- 🔐 修改密码
  - 密码强度验证
  - 确认密码验证

#### 6. 强制修改密码
- 🔒 首次登录检测
- 📝 专门的修改密码页面
- ✅ 修改成功后跳转登录
