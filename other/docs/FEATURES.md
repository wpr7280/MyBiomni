## 📋 页面路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/login` | 登录页 | 用户登录 |
| `/auth/sso` | SSO 登录 | 单点登录 |
| `/change-password` | 修改密码 | 强制修改密码 |
| `/profile` | 个人中心 | 用户信息和设置 |
| `/` | 对话页面 | 主要功能页面 |
