# Biomni Agent 应用系统初始化说明

## 1. 初始化概述

Biomni Agent 应用在首次启动时会自动执行系统初始化流程，创建默认管理员账号和基础配置。

### 1.1 初始化时机
- 系统首次启动时
- 数据库中没有管理员账号时
- 通过检查 `admins` 表记录数判断是否需要初始化

### 1.2 初始化内容
1. 创建默认管理员账号
2. 生成随机初始密码
3. 初始化系统配置
4. 创建默认配额模板
5. 初始化文档分类

---

## 2. 默认管理员账号

### 2.1 账号信息

| 字段 | 值 |
|------|-----|
| 用户名 | `admin` |
| 密码 | 随机生成（16位强密码） |
| 邮箱 | `admin@biomni.com` |
| 角色 | `super_admin` |
| 状态 | 启用 |
| 强制修改密码 | 是 |

### 2.2 密码规则

初始密码由系统自动生成，满足以下要求：
- 长度：16 位
- 包含大写字母（A-Z）
- 包含小写字母（a-z）
- 包含数字（0-9）
- 包含特殊字符（!@#$%^&*）
- 字符随机排列

**示例密码**: `A7b#K9m@P2x$Q5w!`

## 3. 初始化流程

### 3.1 启动检查

```
应用启动
    ↓
检查 admins 表
    ↓
是否有记录？
    ├─ 是 → 跳过初始化
    └─ 否 → 执行初始化
```

### 3.2 初始化步骤

```
1. 生成随机密码
    ↓
2. 创建管理员账号
    ↓
3. 加密存储密码
    ↓
4. 设置强制修改密码标记
    ↓
5. 输出初始密码到日志
    ↓
6. 初始化系统配置
    ↓
7. 创建默认配额模板
    ↓
8. 初始化文档分类
    ↓
9. 完成初始化
```

### 3.3 日志输出

系统初始化完成后，会在控制台输出以下信息：

```
================================================================================
SYSTEM INITIALIZATION COMPLETED
Default Admin Account Created:
  Username: admin
  Password: A7b#K9m@P2x$Q5w!
IMPORTANT: Please change the password on first login!
================================================================================
```

**重要提示**:
- 初始密码仅在控制台显示一次
- 请立即记录初始密码
- 首次登录后必须修改密码
- 建议使用密码管理工具保存

## 4. 首次登录流程

### 4.1 登录步骤

1. **访问管理后台**
   - URL: `https://your-domain.com/admin`
   - 或: `http://localhost:3000/admin` (开发环境)

2. **输入初始凭证**
   - 用户名: `admin`
   - 密码: 从控制台日志中复制

3. **登录响应**
   ```json
   {
     "code": 200,
     "data": {
       "token": "...",
       "forcePasswordChange": true,
       "admin": {
         "username": "admin",
         "role": "super_admin"
       }
     }
   }
   ```

4. **强制修改密码**
   - 系统检测到 `forcePasswordChange: true`
   - 自动跳转到修改密码页面
   - 只能访问修改密码和登出接口

5. **修改密码**
   - 输入旧密码（初始密码）
   - 输入新密码（需满足强度要求）
   - 确认新密码

6. **重新登录**
   - 使用新密码登录
   - 开始使用系统

### 4.2 密码强度要求

新密码必须满足以下要求：
- 最小长度：8 位
- 包含大写字母
- 包含小写字母
- 包含数字
- 建议包含特殊字符

**示例合格密码**:
- `MyPass123!`
- `Secure@2025`
- `Admin#Pass99`

## 6. 安全建议

### 6.1 密码管理

✅ **推荐做法**:
- 使用密码管理器保存初始密码
- 首次登录后立即修改密码
- 定期更换密码（建议每 90 天）
- 使用强密码（12 位以上）
- 不要在多个系统使用相同密码

❌ **避免做法**:
- 将密码写在纸上或文本文件中
- 使用简单密码（如 123456）
- 与他人共享管理员账号
- 长期不修改密码

### 6.2 账号安全

1. **限制管理员数量**
   - 只创建必要的管理员账号
   - 为不同职责创建不同角色

2. **启用登录保护**
   - 系统自动启用登录失败锁定（5次失败锁定30分钟）
   - 记录所有登录日志

3. **定期审计**
   - 定期检查操作日志
   - 审查用户权限
   - 删除不再使用的账号

### 6.3 网络安全

1. **使用 HTTPS**
   - 生产环境必须启用 HTTPS
   - 配置有效的 SSL 证书

2. **防火墙配置**
   - 限制管理后台访问 IP
   - 只开放必要的端口

3. **定期备份**
   - 每天自动备份数据库
   - 保留至少 30 天的备份

## 7. 故障排查

### 7.1 初始化失败

**问题**: 系统启动时初始化失败

**可能原因**:
1. 数据库连接失败
2. 数据库权限不足
3. 表结构未创建

**解决方案**:
```bash
# 1. 检查数据库连接
mysql -h localhost -u root -p

# 2. 检查数据库是否存在
SHOW DATABASES LIKE 'biomni_app';

# 3. 检查表是否创建
USE biomni_app;
SHOW TABLES;

# 4. 手动执行初始化脚本
SOURCE /path/to/init.sql;
```

### 7.2 找不到初始密码

**问题**: 控制台日志中找不到初始密码

**解决方案**:

**方法 1: 查看日志文件**
```bash
# 查看应用日志
tail -n 100 logs/application.log | grep "Default Admin"

# 或搜索完整日志
grep -A 5 "SYSTEM INITIALIZATION" logs/application.log
```

**方法 2: 重置管理员密码**
```sql
-- 连接数据库
mysql -u root -p biomni_app

-- 生成新密码的 BCrypt 哈希
-- 使用在线工具: https://bcrypt-generator.com/
-- 或使用 Python:
-- python -c "from passlib.hash import bcrypt; print(bcrypt.hash('NewPassword123'))"

-- 更新密码
UPDATE admins 
SET password = '$2a$10$...', 
    force_password_change = 1 
WHERE username = 'admin';
```

**方法 3: 重新初始化**
```sql
-- 警告：此操作会删除所有管理员账号
DELETE FROM admins;

-- 重启应用，系统会重新初始化
```

### 7.3 无法修改密码

**问题**: 首次登录后无法修改密码

**可能原因**:
1. 旧密码输入错误
2. 新密码不符合强度要求
3. Token 已过期

**解决方案**:
1. 确认旧密码正确
2. 检查新密码是否满足要求（至少8位，包含大小写字母和数字）
3. 重新登录获取新 Token
4. 查看后端日志获取详细错误信息

## 8. 常见问题

### Q1: 可以跳过首次修改密码吗？

**A**: 不可以。这是强制的安全措施，确保初始密码不会被长期使用。

### Q2: 初始密码可以自定义吗？

**A**: 不可以。初始密码由系统随机生成，确保安全性。但您可以在首次登录后修改为自己喜欢的密码。

### Q3: 忘记修改后的密码怎么办？

**A**: 需要通过数据库手动重置密码（参见 7.2 节），或联系系统管理员。

### Q4: 可以创建多个管理员吗？

**A**: 可以。使用 super_admin 账号登录后，可以在用户管理中创建其他管理员账号。

### Q5: 初始化会覆盖现有数据吗？

**A**: 不会。初始化只在数据库为空时执行，不会影响现有数据。

### Q6: 如何禁用强制修改密码？

**A**: 不建议禁用。如果确实需要，可以在数据库中将 `force_password_change` 字段设为 0。
