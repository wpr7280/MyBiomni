## 🖱️ 可拖动调节宽度

### 使用方法
1. 将鼠标移到对话区域和执行面板之间的分隔线
2. 鼠标变为 `↔` 形状
3. 按住鼠标左键拖动
4. 释放鼠标完成调整

### 宽度范围
- 最小宽度：300px
- 最大宽度：600px
- 默认宽度：420px

### 视觉反馈
- 悬停时：分隔线变为灰色
- 拖动时：分隔线变为蓝色
- 中间显示：⋮ 图标
