## 2. 方案设计

### 方案 A：在 Python Agent 中实现（推荐）

#### 2.1 Token 统计

**位置**：A1 Agent 的 `generate` 函数中

```python
def generate(state: AgentState) -> AgentState:
    messages = [SystemMessage(content=system_prompt)] + state["messages"]
    
    # 调用 LLM
    response = self.llm.invoke(messages)
    
    # 统计 Token（如果 LLM 支持）
    if hasattr(response, 'usage_metadata'):
        input_tokens = response.usage_metadata.get('input_tokens', 0)
        output_tokens = response.usage_metadata.get('output_tokens', 0)
        
        # 累加到 callback
        if hasattr(self, '_callback'):
            self._callback.total_input_tokens += input_tokens
            self._callback.total_output_tokens += output_tokens
    
    # ... 其他逻辑
```

**优点**：
- ✅ 数据最准确（直接从 LLM 获取）
- ✅ 实时统计
- ✅ 支持多轮对话累加

**缺点**：
- ❌ 需要修改 A1 代码
- ❌ 不同 LLM 的 API 可能不同

**位置**：Python WebSocket 接收消息时

**配额检查逻辑**：

```python
async def check_user_quota(user_id: int, db: Session) -> bool:
    # 从数据库查询用户配额
    quota = db.query(UserQuota).filter(UserQuota.user_id == user_id).first()
    
    # 查询今日使用量
    today = datetime.now().date()
    usage = db.query(QuotaUsageRecord).filter(
        QuotaUsageRecord.user_id == user_id,
        QuotaUsageRecord.record_date == today
    ).first()
    
    # 检查每日对话次数
    if usage and usage.daily_conversation_used >= quota.daily_conversation_limit:
        return False
    
    # 检查每日 Token 限制
    if usage and usage.daily_token_used >= quota.daily_token_limit:
        return False
    
    # 检查并发任务限制（使用 Redis）
    concurrent_tasks = await redis_client.get(f"user:{user_id}:concurrent_tasks")
    if concurrent_tasks and int(concurrent_tasks) >= quota.concurrent_task_limit:
        return False
    
    return True
```

#### 2.3 配额更新

**位置**：Agent 执行完成后

```python
async def handle_agent_execution(...):
    # 执行 Agent
    result = await AgentService.execute_agent_stream(...)
    
    # 更新配额
    await update_user_quota(
        user_id=user_id,
        tokens=result['total_tokens'],
        conversation_count=1,
        db=db
    )

async def update_user_quota(user_id, tokens, conversation_count, db):
    today = datetime.now().date()
    
    # 获取或创建今日记录
    usage = db.query(QuotaUsageRecord).filter(
        QuotaUsageRecord.user_id == user_id,
        QuotaUsageRecord.record_date == today
    ).first()
    
    if not usage:
        usage = QuotaUsageRecord(
            user_id=user_id,
            record_date=today
        )
        db.add(usage)
    
    # 更新使用量
    usage.daily_conversation_used += conversation_count
    usage.daily_token_used += tokens
    
    db.commit()
```

## 4. 数据库表设计

### 4.1 用户配额表（user_quotas）

```sql
CREATE TABLE `user_quotas` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `user_id` INT NOT NULL COMMENT '用户ID',
  `daily_conversation_limit` INT NOT NULL DEFAULT 50 COMMENT '每日对话次数限制',
  `daily_token_limit` INT NOT NULL DEFAULT 100000 COMMENT '每日Token限制',
  `concurrent_task_limit` INT NOT NULL DEFAULT 3 COMMENT '并发任务限制',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_quotas_user` (`user_id`),
  CONSTRAINT `fk_user_quotas_users` FOREIGN KEY (`user_id`) REFERENCES `admin` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户配额表';
```

### 4.2 配额使用记录表（quota_usage_records）

```sql
CREATE TABLE `quota_usage_records` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `user_id` INT NOT NULL COMMENT '用户ID',
  `record_date` DATE NOT NULL COMMENT '记录日期',
  `daily_conversation_used` INT NOT NULL DEFAULT 0 COMMENT '当日对话次数',
  `daily_token_used` INT NOT NULL DEFAULT 0 COMMENT '当日Token使用量',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_quota_usage_user_date` (`user_id`, `record_date`),
  CONSTRAINT `fk_quota_usage_users` FOREIGN KEY (`user_id`) REFERENCES `admin` (`id`) ON DELETE CASCADE
```

### 5.3 并发任务限制

```python
# 使用 Redis 记录并发任务数
async def increment_concurrent_tasks(user_id):
    key = f"user:{user_id}:concurrent_tasks"
    await redis_client.incr(key)
    await redis_client.expire(key, 3600)  # 1小时过期

async def decrement_concurrent_tasks(user_id):
    key = f"user:{user_id}:concurrent_tasks"
    await redis_client.decr(key)
```

### 5.4 单次对话 Token 限制

```python
# 在 callback 中检查
class WebSocketCallback:
    def on_llm_call(self, input_tokens, output_tokens):
        self.total_tokens += input_tokens + output_tokens
        
        # 检查单次对话 Token 限制
```

## 9. Token 统计方案

### 9.1 从 LLM Response 获取

```python
response = self.llm.invoke(messages)

# Anthropic Claude
if hasattr(response, 'usage_metadata'):
    input_tokens = response.usage_metadata.get('input_tokens', 0)
    output_tokens = response.usage_metadata.get('output_tokens', 0)

# OpenAI
elif hasattr(response, 'response_metadata'):
    usage = response.response_metadata.get('token_usage', {})
    input_tokens = usage.get('prompt_tokens', 0)
    output_tokens = usage.get('completion_tokens', 0)

# 估算（如果 LLM 不提供）
else:
    input_tokens = len(str(messages)) // 4
    output_tokens = len(response.content) // 4
```

### 9.2 通过 Callback 传递

```python
class WebSocketCallback:
    def __init__(self, ...):
        self.total_input_tokens = 0
        self.total_output_tokens = 0
    
    def on_llm_call(self, input_tokens, output_tokens):
        self.total_input_tokens += input_tokens
        self.total_output_tokens += output_tokens
        
        # 实时推送到前端
        await self.manager.send_message(str(self.conversation_id), {
            'type': 'token_usage',
            'inputTokens': input_tokens,
            'outputTokens': output_tokens,
            'totalTokens': self.total_input_tokens + self.total_output_tokens
        })
```

## 11. 总结

### 推荐方案

**Token 统计**：
- ✅ 在 A1 Agent 的 `generate` 函数中获取
- ✅ 通过 callback 传递给 WebSocket
- ✅ 保存到数据库

- ✅ 在 Python WebSocket 中检查

- ✅ Agent 执行完成后更新

- ✅ Token 统计准确（从 LLM 获取）
