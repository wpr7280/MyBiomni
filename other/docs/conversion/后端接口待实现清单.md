## 2. Python Agent 服务接口

### 2.1 WebSocket 接口（需要实现）

| 接口 | 类型 | 路径 | 状态 | 说明 |
|------|------|------|------|------|
| 对话连接 | WebSocket | /ws/chat/{conversationId} | ⏳ 待实现 | 建立 WebSocket 连接 |

**功能要求**：
- 验证 JWT Token（Spring Boot 生成的）
- 接收用户消息
- 执行 WarpHelix Agent
- 实时推送执行步骤
- 保存执行步骤到数据库
- 保存 Assistant 消息到数据库
- 调用 Spring Boot 内部 API 更新配额

### 2.2 内部回调（需要实现）

Python Agent 需要调用 Spring Boot 的内部 API：

```python
# 更新配额
POST http://spring-boot:8083/api/internal/quota/update
Headers:
  X-Internal-Secret: your-secret
Body:
  {
    "user_id": 123,
    "tokens": 1500,
    "conversation_count": 1,
    "duration_ms": 5000
  }
```

## 3. 接口详细规格

### 3.1 获取对话列表

**请求**：
```
GET /api/conversations?page=1&size=20
Headers:
  Authorization: Bearer {token}
```

**响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "title": "蛋白质结构分析",
      "status": "active",
      "messageCount": 5,
      "lastMessageAt": "2025-01-20T10:30:00",
      "createdAt": "2025-01-20T09:00:00",
      "updatedAt": "2025-01-20T10:30:00"
    }
  ]
}
```

### 3.2 创建对话

**请求**：
```
POST /api/conversations
Headers:
  Authorization: Bearer {token}
Body:
  {
    "title": "新对话"
  }
```

**响应**：
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "id": 4,
    "title": "新对话",
    "status": "active",
    "messageCount": 0,

}
```

## 4. Python Agent WebSocket 协议

### 4.1 连接

```
ws://localhost:8000/ws/chat/{conversationId}?token={jwt_token}
```

### 4.2 客户端 → 服务器

```json
{
  "type": "send_message",
  "content": "什么是蛋白质的二级结构？"
}
```

### 4.3 服务器 → 客户端

#### 执行开始
```json
{
  "type": "execution_start",
  "message_id": 1
}
```

#### 执行步骤
```json
{
  "type": "execution_step",
  "step": {
    "id": 1,
    "conversationId": 1,
    "messageId": 2,
    "stepOrder": 1,
    "stepType": "tool_call",
    "stepName": "搜索知识库",
    "toolName": "search_knowledge",
    "toolInput": {"query": "protein structure"},
    "toolOutput": "找到 5 篇相关文献",
    "status": "success",
    "durationMs": 1200,
    "startedAt": "2025-01-20T09:00:01",
    "completedAt": "2025-01-20T09:00:02"
  }
}
```

#### 执行完成
```json
{
  "type": "execution_complete",
  "message": {
    "id": 2,
    "conversationId": 1,
    "role": "assistant",
    "content": "蛋白质的二级结构是指...",
    "contentType": "markdown",
    "tokens": 150,
    "inputTokens": 15,
    "outputTokens": 135,
    "createdAt": "2025-01-20T09:00:30"
  }
}
```

#### 执行错误
```json
{
  "type": "execution_error",
  "error": "配额不足"
}
```
