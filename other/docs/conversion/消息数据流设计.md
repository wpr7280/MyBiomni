# 消息数据流设计

## 1. 核心概念

### 1.1 两种消息来源

```
┌─────────────────────────────────────────────────────────┐
│                    消息来源                              │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  1. 历史消息（已保存在数据库）                           │
│     - 从 Spring Boot API 获取                           │
│     - 页面加载时获取                                     │
│     - 切换对话时获取                                     │
│                                                          │
│  2. 新消息（实时生成）                                   │
│     - 用户消息：前端立即显示                             │
│     - AI 消息：通过 WebSocket 实时推送                   │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 2. 完整数据流

### 2.1 打开对话时（加载历史）

```
┌─────────────────────────────────────────────────────────┐
│  1. 用户点击对话                                         │
│     ↓                                                    │
│  2. 前端调用 Spring Boot API                            │
│     GET /api/messages/list?conversationId=1             │
│     ↓                                                    │
│  3. Spring Boot 从数据库查询历史消息                     │
│     SELECT * FROM messages                              │
│     WHERE conversation_id = 1                           │
│     ORDER BY created_at ASC                             │
│     ↓                                                    │
│  4. 返回历史消息列表                                     │
│     [                                                    │
│       { role: 'user', content: '问题1' },              │
│       { role: 'assistant', content: '回答1' },         │
│       { role: 'user', content: '问题2' },              │
│       { role: 'assistant', content: '回答2' }          │
│     ]                                                    │
│     ↓                                                    │
│  5. 前端显示历史消息                                     │
└─────────────────────────────────────────────────────────┘
```

### 2.2 发送新消息时（实时流）

```
┌─────────────────────────────────────────────────────────┐
│  1. 用户输入消息并点击发送                               │
│     ↓                                                    │
│  2. 前端立即显示用户消息（乐观更新）                     │
│     messages.push({ role: 'user', content: '问题3' })  │
│     ↓                                                    │
│  3. 前端调用 Spring Boot API 保存消息                   │
│     POST /api/messages/send                             │
│     { conversationId: 1, content: '问题3' }            │
│     ↓                                                    │
│  4. Spring Boot 保存用户消息到数据库                     │
│     INSERT INTO messages (role, content, ...)           │
│     VALUES ('user', '问题3', ...)                       │
│     ↓                                                    │
│  5. Spring Boot 返回消息 ID                             │
│     { id: 5, role: 'user', content: '问题3' }          │
│     ↓                                                    │
│  6. 前端通过 WebSocket 发送给 Python Agent              │
│     ws.send({ type: 'send_message', content: '问题3' })│
│     ↓                                                    │
│  7. Python Agent 执行 Biomni Agent                      │
│     - 实时推送执行步骤（WebSocket）                      │
│     - 采集 Token 消耗                                   │
│     - 采集执行时长                                       │
│     ↓                                                    │
│  8. Python Agent 保存 AI 消息到数据库                   │
│     INSERT INTO messages (role, content, tokens, ...)   │
│     VALUES ('assistant', '回答3', 150, ...)            │
│     ↓                                                    │
│  9. Python Agent 通过 WebSocket 推送 AI 消息            │
│     ws.send({                                           │
│       type: 'execution_complete',                       │
│       message: { role: 'assistant', content: '回答3' } │
│     })                                                   │
│     ↓                                                    │
│  10. 前端接收并显示 AI 消息                             │
│      messages.push({ role: 'assistant', content: '回答3' })│
└─────────────────────────────────────────────────────────┘
```

## 3. 关键设计点

### 3.1 历史消息

**数据来源**：数据库（已保存）  
**获取方式**：Spring Boot REST API  
**获取时机**：
- 页面加载时
- 切换对话时
- 刷新页面时

**代码位置**：
```typescript
// client/frontend/src/components/ChatWindow.tsx
useEffect(() => {
  loadMessages();  // 加载历史消息
}, [conversationId]);

async function loadMessages() {
  const data = await conversationApi.getMessages(conversationId);
  setMessages(data);  // 设置历史消息
}
```

### 3.2 新消息

**用户消息**：
- **显示时机**：立即显示（乐观更新）
- **保存位置**：Spring Boot API
- **数据流**：前端 → Spring Boot → 数据库

**AI 消息**：
- **显示时机**：WebSocket 推送时显示
- **保存位置**：Python Agent
- **数据流**：Python Agent → 数据库 → WebSocket → 前端

## 4. 代码实现

### 4.1 前端：加载历史消息

```typescript
// client/frontend/src/components/ChatWindow.tsx
export default function ChatWindow({ conversationId }: ChatWindowProps) {
  const { messages, setMessages, sendMessage } = useWebSocket(conversationId);

  // 加载历史消息（从 Spring Boot API）
  useEffect(() => {
    loadMessages();
  }, [conversationId]);

  async function loadMessages() {
    try {
      // 调用 Spring Boot API 获取历史消息
      const data = await conversationApi.getMessages(conversationId);
      setMessages(data);  // 设置历史消息
    } catch (error) {
      console.error('加载消息失败:', error);
    }
  }

  // ...
}
```

### 4.2 前端：发送新消息

```typescript
async function handleSendMessage(content: string) {
  try {
    // 1. 立即显示用户消息（乐观更新）
    const userMessage = {
      id: Date.now(),
      conversationId,
      role: 'user',
      content,
      createdAt: new Date().toISOString(),
    };
    setMessages((prev) => [...prev, userMessage]);
    
    // 2. 调用 Spring Boot API 保存用户消息
    await conversationApi.sendMessage(conversationId, content);
    
    // 3. 通过 WebSocket 发送给 Python Agent 执行
    sendMessage(content);
    
    // 4. AI 消息会通过 WebSocket 推送回来
  } catch (error) {
    console.error('发送消息失败:', error);
  }
}
```

### 4.3 前端：接收 AI 消息

```typescript
// client/frontend/src/hooks/useWebSocket.ts
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  
  if (data.type === 'execution_complete') {
    // 接收到 AI 消息，添加到消息列表
    setMessages((prev) => [...prev, data.message]);
  }
};
```

    @Valid @RequestBody SendMessageRequest request,
    @AuthenticationPrincipal AdminVO currentUser

    // 1. 检查配额

## 6. 数据流总结

### 6.1 历史消息

```
数据库 → Spring Boot API → 前端显示
```

**特点**：
- ✅ 已保存在数据库
- ✅ 通过 REST API 获取
- ✅ 分页加载
- ✅ 页面加载时获取

### 6.2 用户消息（新发送）

```
前端输入 → 立即显示 → Spring Boot API → 数据库
```

**特点**：
- ✅ 前端立即显示（乐观更新）
- ✅ 通过 REST API 保存
- ✅ Spring Boot 负责保存

### 6.3 AI 消息（新生成）

```
Python Agent 执行 → 保存到数据库 → WebSocket 推送 → 前端显示
```

**特点**：
- ✅ Python Agent 负责保存
- ✅ 通过 WebSocket 实时推送
- ✅ 前端接收后显示

---

## 7. 为什么这样设计？

### 7.1 历史消息用 REST API

**原因**：
- ✅ 历史消息是静态数据，不需要实时推送
- ✅ REST API 更简单、更可靠
- ✅ 支持分页加载
- ✅ 可以缓存

### 7.2 新消息用 WebSocket

**原因**：
- ✅ AI 消息生成需要时间（几秒到几分钟）
- ✅ 需要实时推送执行步骤
- ✅ 需要流式返回结果
- ✅ 用户体验更好

### 7.3 用户消息立即显示

**原因**：
- ✅ 提升用户体验（不需要等待 API 返回）
- ✅ 乐观更新（假设 API 调用会成功）
- ✅ 如果失败，可以显示错误并移除

## 10. 总结

### 数据流向

| 消息类型 | 数据来源 | 传输方式 | 保存位置 | 显示时机 |
|---------|---------|---------|---------|---------|
| 历史消息 | 数据库 | REST API | Spring Boot | 页面加载时 |
| 用户消息 | 前端输入 | REST API | Spring Boot | 立即显示 |
| AI 消息 | Agent 生成 | WebSocket | Python Agent | 推送时显示 |

### 关键点

1. ✅ **历史消息**：从 Spring Boot API 获取（REST）
2. ✅ **用户消息**：前端立即显示 + Spring Boot 保存
3. ✅ **AI 消息**：Python Agent 保存 + WebSocket 推送

这样设计的好处：
- ✅ 历史消息加载快速（REST API）
- ✅ 新消息实时推送（WebSocket）
- ✅ 用户体验好（立即反馈）
- ✅ 数据准确（Python 采集 Token）
