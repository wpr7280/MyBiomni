# Biophysics

生物物理学工具集。

## 可用工具

- **predict_protein_disorder_regions**: Predicts intrinsically disordered regions (IDRs) in a protein sequence using IUP
- **analyze_cell_morphology_and_cytoskeleton**: Quantifies cell morphology and cytoskeletal organization from fluorescence micro
- **analyze_tissue_deformation_flow**: Quantify tissue deformation and flow dynamics from microscopy image sequence

## 使用示例

调用 `predict_protein_disorder_regions` 进行生物物理学相关分析。
