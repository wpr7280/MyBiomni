# Protocols

实验方案工具集。

## 可用工具

- **search_protocols**: Search protocols.io for public protocols matching a keyword
- **get_protocol_details**: Retrieve detailed metadata for a specific protocols.io protocol by ID
- **list_local_protocols**: List available protocol files in the local biomni/tool/protocols/ directory. Inc
- **read_local_protocol**: Read the contents of a local protocol file from biomni/tool/protocols/. Use list

## 使用示例

调用 `search_protocols` 进行实验方案相关分析。
